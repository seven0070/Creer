## Usage in Cursor

- Auto-discovered from `.cursor/skills/` (and via `skills/` for GitHub remote installs)
- Invoke with `/praisonai` or `@praisonai` in Agent chat
- Or install via **Customize → Rules → Add Rule → Remote Rule (Github)** pointing at this repository

Skill format follows the [Agent Skills](https://agentskills.io) standard.

Source material for the PraisonAI skill: [MervinPraison/PraisonAI](https://github.com/MervinPraison/PraisonAI).
