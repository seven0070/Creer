# PraisonAI

## When to use

- User asks about PraisonAI, `praisonaiagents`, agent workflows, or multi-agent systems
- Building agents, MCP integrations, or automation with PraisonAI
- Need installation steps, API references, or code examples

## Instructions

1. Use the **praisonai Docs** MCP server to search the official documentation before answering.
2. Prefer [docs.praison.ai](https://docs.praison.ai) and the [PraisonAI GitHub repo](https://github.com/MervinPraison/PraisonAI) as authoritative sources.
3. For local agent execution, suggest `pip install praisonaiagents` or `uvx praisonai-mcp` with `OPENAI_API_KEY` set.
4. PraisonAI is not a Cursor plugin marketplace; integration is via MCP (docs server or `praisonai-mcp` tools server).
